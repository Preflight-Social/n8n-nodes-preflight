# Example workflows

Five workflows for the Preflight node. Import a JSON file in n8n with **Import from File**, pick your Preflight credential and your channels, and read the sticky note on the canvas.

| File | Trigger | Uses | Result |
| --- | --- | --- | --- |
| `01-rss-ai-caption-validate-draft.json` | Every hour | RSS Read, Remove Duplicates, Basic LLM Chain + OpenAI | Drafts in Preflight, only for captions every network accepts |
| `02-google-sheets-content-calendar.json` | Every 15 minutes | Google Sheets | Rows `Ready` → scheduled (or queued when there is no time); row updated with the post ID or the reason it was refused |
| `03-vertical-video-shorts-reels-tiktok.json` | n8n Form | – | One vertical video checked and queued to YouTube Shorts, Instagram Reels and the TikTok inbox |
| `04-notion-database-to-preflight.json` | Every 15 minutes | Notion | Pages `Ready` → scheduled; page updated with the post ID or the reason |
| `05-failed-post-slack-telegram-alert.json` | Preflight Trigger (`post.failed`) | Slack, Telegram | An alert per failed channel with the reason and a link to the post |

What they have in common:

- **Validate before create.** Every workflow asks Preflight whether each network would accept the post, and only creates it when the answer is yes. A refusal comes back as a plain sentence such as "Text is 385 characters; Bluesky allows 300."
- **Stable idempotency keys**, built from the article link, the sheet row or the Notion page and a hash of the text, so running a workflow twice never makes two posts.
- **Nothing goes live by surprise.** Template 1 makes drafts; TikTok in template 3 goes to the creator's inbox with privacy *Only me* until you change it.

## Rebuilding

The JSON files are generated by `build.py`. Edit the script, then run:

```bash
python3 templates/build.py
```
